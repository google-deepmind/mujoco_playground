MuJoCo Playground
Playground 1.0 RSS 2025

MuJoCo Playground 1.0 is an open-source suite of sim and real environments built natively on MuJoCo, MuJoCo Warp, MuJoCo Studio, and reaf-sim. We rebuilt Playground on a stack that decouples hardware and sensor I/O (DeviceLayer) from plain-PyTorch task logic (TaskLayer). This new architecture makes sim-to-real workflows with MuJoCo more seamless than ever, from large batch RL policy training to agentic VLM harness development.

Quickstart

Train and visualize a Cartpole policy directly with uvx. 

# Train CartpoleBalance (~1 min on CPU)
uvx --default-index https://pypi.org/simple --python 3.13 --from "playground[rl]>=1.0" \
  python -m mujoco_playground.rl.rsl_rl.train \
  --env=CartpoleBalance \
  --logdir=/tmp/rslrl_logs/cartpole_balance \
  --overrides='{"nworld": 64}'

# Play trained policy in MuJoCo Studio web viewer
uvx --default-index https://pypi.org/simple --python 3.13 --from "playground[rl]>=1.0" \
  python -m mujoco_playground.rl.rsl_rl.play \
  --env=CartpoleBalance --resume_path=/tmp/rslrl_logs/cartpole_balance
# Train CartpoleBalance (CUDA 12 driver)
uvx --python 3.13 \
  --index https://download.pytorch.org/whl/cu129 \
  -f https://github.com/NVIDIA/warp/releases/expanded_assets/v1.18.0 \
  --with "warp-lang==1.18.0+cu12" \
  --from "playground[rl]>=1.0" \
  python -m mujoco_playground.rl.rsl_rl.train \
  --env=CartpoleBalance \
  --logdir=/tmp/rslrl_logs/cartpole_balance

# Play trained policy in MuJoCo Studio web viewer
